When to use each variant

VariantWhen to useNever use for
Outline Secondary status info alongside other data in a table row or card The only element on screen — too subtle alone
Filled Single most important status. Sidebar counts. Alerts requiring immediate attention. More than one per row — creates visual noise
Role Showing which role performed an action (audit trail, query thread) Navigation or page headers — use the role chip block there
3 Sidebar nav item counts. Unread counts. Items requiring action. Data values — use mono text for actual numbers in tables
